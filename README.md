
# Java JDBC Program

## Aim
To write a Java program to connect to a MySQL database using JDBC and retrieve user records.

## Technologies Used
- Java
- JDBC
- MySQL

## Database Details
- Database Name: mydatabase
- Table Name: users
- Columns: id, username, email

## Program Description
This program connects to a MySQL database using JDBC, retrieves all records from the users table, and displays the user ID, username, and email.

It also handles database errors using SQLException.

## Expected Output
ID: 1
Username: Ravi
Email: ravi@example.com

ID: 2
Username: Sita
Email: sita@example.com

ID: 3
Username: Kiran
Email: kiran@example.com

## How to Run
1. Install Java and MySQL.
2. Create the mydatabase database and users table.
3. Add the MySQL JDBC driver.
4. Configure the database URL, username, and password.
5. Compile and run the Java program.
